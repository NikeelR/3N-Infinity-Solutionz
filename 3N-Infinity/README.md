## Design direction

- Hero: single corporate message with a 2x2 / four-panel visual composition.
- Business section: 4-column x 2-row desktop grid for the 8 sectors.
- About section: concise corporate positioning.
- Capabilities, story, process and contact sections use the same editorial/corporate language and spacing.
- Responsive layout collapses to 2 columns and then 1 column on smaller screens.
- Supplied 3N Infinity logo is used in header, mobile menu and footer.
